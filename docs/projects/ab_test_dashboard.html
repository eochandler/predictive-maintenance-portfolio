HYPOTHESIS TEST · TWO-PROPORTION Z-TEST

Should this company ship the new landing page?

An e-commerce company built a new landing page to increase conversions and ran an A/B test on 294,478 users. This analysis walks through the full rigor required to trust the answer. This tests beyond "did the number just go up"

p=0.91
Verdict: Do not ship the new page. The observed difference is not statistically significant, and the direction is actually slightly negative. The company should keep the current page rather than replace it based on this test.

Step 1 — Data quality, before trusting anything

1.32% of users were logged with a mismatched group/page assignment (e.g. a "control" user who somehow saw the new page) These can't be attributed to either version and must be excluded before any test is valid.

    Step 2 — Sample Ratio Mismatch (SRM) check

    Before trusting a conversion-rate comparison, verify the randomization itself worked by checking that users were actually split ~50/50 as intended. A failed SRM check invalidates a test regardless of what the conversion numbers say.

    Step 3 — The main result

    Control (old page) converted at 12.04% treatment (new page) converted at 11.88%. a difference of -0.16 percentage points, with a 95% confidence interval that spans zero.

    Step 4 — Was this test even powered enough?

    A null result can mean "truly no effect" or "not enough data to detect a real one." With 290K+ users, this test could reliably detect an effect as small as 0.35 percentage points Any smaller than that, and the test is underpowered, not evidence of "no effect."

    The observed effect (-0.16pp) falls well within the range this test could not reliably distinguish from zero. So "not significant" here is a trustworthy null.

    Step 5 — Daily trend (novelty effect check)

    There is no meaningful upward or downward drift over the 23-day test window in either group, this rules out a "novelty effect" that fades over time.

    Business recommendation

    Keep the current page. Shipping the new page would very likely not improve conversion, and directionally leans slightly negative. If the business believes a smaller effect (under 0.35pp) could still be commercially meaningful, the next step is not to re-run this same test. Run a longer test with more traffic, since this sample size cannot resolve an effect that small either way.
